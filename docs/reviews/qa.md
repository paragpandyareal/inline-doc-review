Working as designed or correct: `.xlsx` is excluded from auto-open, as the README says; empty, corrupt and non-PDF files, scanned PDFs, and rotated and owner-only PDFs are handled; `#DIV/0!`, `#REF!` and `#CALC?` render as errors.

## What works well
- The core loop is solid: select, comment, edit, delete-by-clearing, Send / Edit before sending, spinner, glow and fade. The original 25 tests plus my flow tests confirm it.
- Feedback carries both a precise anchor and the quoted text, which mitigates several anchor issues (B14) for Claude.
- Keyboard clamping, sheet switching and the file dropdown are robust. All four surfaces draw without throwing. Error paths are clear.
- Markdown handles 50k lines in about 0.3 s; xlsx extraction of 5,000 rows × 120 columns takes about 0.35 s and is capped correctly.
